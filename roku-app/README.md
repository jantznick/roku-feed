# Roku App

This is the Roku channel that will display the hockey streams.

It fetches a content feed (a JSON file) from a cloud provider, which is generated by the `scraper` service.
It then displays the available games in a simple UI. When a user selects a game, it will use the local `stream-converter` service to play the video.

## Feed URL

**Default feed URL** (used when no custom URL is set):

```
https://f004.backblazeb2.com/file/roku-hockey/secretfeedfilename.json
```

### Custom feed URL (device-local)

The channel can use an optional custom feed URL. It is stored on the device in `roRegistry` (`section`: `feed`, `key`: `feedUrl`) and is **not** shared with the web/backend settings UIs — those are separate for now.

**On device (sideload testing):**

1. From the main grid, press **Options** (`*` on the remote).
2. Choose **Set Custom Feed URL** and enter a URL that starts with `http://` or `https://`.
3. Choose **Use Default Feed** to clear the custom URL and go back to the default.
4. Choose **Reload Feed** (or save/clear) to refresh content with the active URL.

Helpers live in `source/feedConfig.brs` (`GetFeedUrl`, `SetFeedUrl`, `ClearFeedUrl`).
